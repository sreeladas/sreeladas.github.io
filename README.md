# [Sreela's Personal Website](https://sreeladas.com)

A single-page personal website hosted on GitHub Pages.

## Stack

- HTML + CSS + vanilla JS (no build step)
- [Bootstrap 5](https://getbootstrap.com/) via CDN
- [Font Awesome 6](https://fontawesome.com/) via CDN
- [Google Fonts](https://fonts.google.com/) (Lora + Open Sans)

## Development

Open `index.html` in a browser. No install or build required.
